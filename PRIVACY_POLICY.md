# NETLAB Privacy Policy

**Effective Date:** October 6, 2026

## 1. Data Collection
NETLAB ("the App") is an offline-first mobile application. We do **not** collect, transmit, or share any personal data, analytics, crash reports, or telemetry to external servers.

## 2. Local Storage (Data Safety)
All user data generated by the App is stored securely on your local device using standard web storage technologies (IndexedDB / LocalStorage):
- **User Profile:** XP, Level, and Mastery scores.
- **Topology Data:** Saved networks, topologies, and device configurations.
- **Practice History:** Previous attempts, hints used, and scores.

This data never leaves your device unless you explicitly use the "Export Backup" feature to generate a manual JSON file.

## 3. External Services
Currently, NETLAB does not integrate with any third-party advertising or billing SDKs (AdMob or Google Play Billing). The application runs 100% offline.

## 4. Permissions
The App may request the following native permissions:
- **Haptics / Vibrate:** To provide tactile feedback during application usage.
- No network, location, or sensitive permissions are requested or required.

## 5. Contact
If you have any questions about this Privacy Policy, please contact the developer via the official repository or support channels.
